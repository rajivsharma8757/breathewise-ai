## 2. Evaluation Parameters (from Official Dashboard)
The AI & expert evaluation engine scores submissions against 6 core criteria:
1. **Code Quality:** Structure, maintainability, TypeScript type safety, formatting, and clean component architecture.
2. **Security:** Zero hardcoded API keys/secrets, sanitized inputs, secure environment variable patterns, safe CORS handling.
3. **Efficiency:** Algorithm efficiency, asynchronous data fetching, low-latency API caching, light bundle size (<10 MB repo size requirement).
4. **Testing:** Automated integration and unit tests, clear test coverage, and reproducible test scripts.
5. **Accessibility (a11y):** Semantic HTML, responsive design (desktop & mobile), keyboard navigation, high-contrast visual safety palettes, and bilingual language toggling.
6. **Problem Statement Alignment:** Deep domain solution for winter urban smog decision support (ventilation timing, commute choices, family protection, and explainable recommendations).
